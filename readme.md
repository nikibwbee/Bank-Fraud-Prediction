Bank Fraud Prediction

A machine learning project focused on detecting fraudulent bank transactions using data analysis and predictive modeling. This project uses Python and Jupyter Notebook to analyze transaction patterns and build a fraud prediction model.

Features
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Fraud pattern visualization
Machine Learning model training
Fraud prediction and evaluation
Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
Project Structure
analysis.ipynb — Main notebook containing data analysis, preprocessing, visualization, and model building.
Objective

The main goal of this project is to identify whether a bank transaction is fraudulent or legitimate based on transaction-related features.
